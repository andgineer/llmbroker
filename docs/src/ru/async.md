# Асинхронность

`AsyncBroker` — основной движок; `Broker` — его блокирующая обёртка. Методы те
же, только с `await`:

```python
async with llmbroker.AsyncBroker("llms.toml") as llms:
    reply = await llms.ask("Привет")
    print(reply.text)
```

Стриминг — только асинхронный: пул отдаёт дельты по мере поступления, с
роутингом и фейловером:

```python
    async for delta in llms.stream("Напиши хокку про брокеров"):
        print(delta, end="", flush=True)
```

Что фейловер успевает спасти посреди стрима, а что нет — см.
[Прямые вызовы модели](direct.md).

Асинхронный tool-цикл — `await llmbroker.arun_tool_loop(...)`, см.
[Инструменты и агенты](tools.md).

## Один процесс, один файл, без шага инициализации

Для однопроцессного сервиса sqlite держит модели, ключи и журнал в одном файле, а
`sync=` наполняет его перед первым вызовом:

```python
async with llmbroker.AsyncBroker("broker.db", sync="freetier") as llms:
    print((await llms.ask("Привет")).text)
```

База стартует пустой, а обновление выполняется до инициализации пула — отдельного
шага инициализации помнить не нужно. Оно best-effort: если каталог недоступен, в
лог уйдёт предупреждение, а процесс стартует на том, что уже лежит в файле.

Для нескольких процессов или хостов делайте синхронизацию один раз в задаче
деплоя — см. [Серверы и кластеры](server.md#datasource).
