# CLI

Ничего из этого для работы с llmbroker не нужно — `Broker()` сам скачивает пул.
Две команды покрывают ровно то, чего llmbroker не может сделать за вас: получить
ключи провайдеров и выбрать платную модель, которую вы хотите звать по имени.

Обе работают офлайн: копия обоих курируемых списков вшита в пакет, поэтому машина
без сети откатывается на неё, а не падает. Эта копия заморожена на той версии
llmbroker, которую вы поставили, поэтому при её использовании команда сообщает об
этом в stderr.

## env — сформировать .env с ключами

```bash
llmbroker env > .env              # ключи, нужные списку этой установки
llmbroker env freetier > .env     # или сразу по имени пресета, пока списка ещё нет
```

Печатает заготовку `.env`: над каждым ключом — подсказка, где его получить:

```
# OPENROUTER_API_KEY — Create a free API key at [openrouter](https://openrouter.ai/keys).
OPENROUTER_API_KEY=
```

Без аргумента читает список в собственном каталоге llmbroker — пул, за которым
брокер уже следует, плюс всё, что положил туда `add-model`. Это повседневная
форма.

Имя пресета нужно, когда локального списка ещё нет или когда реестр брокера живёт
в базе и локального списка нет вовсе:

- `freetier` — бесплатные endpoints от Groq, OpenRouter и Gemini

Сами ключи получите у провайдеров и впишите. Брокер сам читает `.env` в рабочем
каталоге; переменная окружения всегда важнее его. Ключи вообще не обязаны лежать
в `.env` — см. [API-ключи](secrets.md).

## add-model — добавить свою платную модель

```bash
llmbroker add-model                                          # интерактивно
llmbroker add-model --provider anthropic --model claude-opus-5
```

Дописывает модель в список этой установки как вашу собственную запись: её зовут
через `broker.direct(...)`, и пул её никогда не маршрутизирует. См.
[Свои модели](direct.md).

## Чего CLI не делает

Команды, обновляющей список, нет. Брокер держит собственный список свежим сам
(см. [Базовое использование](usage.md#sync)), а брокер на реестре в БД обновляет
его точка входа приложения вызовом `broker.sync("freetier")` — см.
[Серверы и кластеры](server.md#sync). Так конфигурация подключения и её секреты
остаются в одном месте, а слияние происходит там, где видны ключи, которые
приложение действительно разрешит: слияние, которое их не видит, сохранило бы все
записи.
