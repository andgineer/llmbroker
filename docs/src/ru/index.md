# llmbroker

Объедините множество бесплатных, ограниченных лимитами LLM в одну надёжную
модель — без оплаты премиум-подписки и без единой точки отказа. Никаких тяжёлых
зависимостей наподобие LangChain.

## Быстрый старт

[Установите llmbroker](installation.md), получите ключ и вызывайте:

```bash
llmbroker env freetier > .env   # какие ключи нужны и где их взять
```

```python
llms = llmbroker.Broker()
print(llms.ask("Привет, как дела?").text)
```

Это вся настройка — никакого конфиг-файла. `Broker()` поднимает курируемый пул
бесплатных моделей, читает ключи из окружения (и из `.env` в рабочем каталоге) и
сам поддерживает список моделей актуальным.

Заполните те ключи, которые легко получить: модель без ключа просто остаётся
неактивной. Если модель упёрлась в rate limit, брокер охладит её и переключится
на следующую — вы получаете ответ, а не ошибку, пока жива хотя бы одна модель.

Нужна ещё и платная модель? Назовите её — она вызывается напрямую и никогда не
попадает в пул:

```python
llms = llmbroker.Broker(direct=["opus"])
llms.ask("Сделай выжимку")                     # бесплатный пул, с маршрутизацией
llms.direct("opus").ask("А теперь сложное")    # Claude Opus, текущая версия
```

Хотите держать список моделей в файле, который проходит ревью? Так тоже
можно — см. [Использование](usage.md#file).

## Возможности

- **Без конфигурации** — `Broker()` не требует ни файла, ни аргументов; конфиг-файл
  нужен тем, кто хочет видеть список моделей в диффе.
- **Автоматический failover** — ошибка только когда не осталось совсем никого
  (`NoLLMAvailableError`).
- **Chat, инструменты и агенты** — `ask`, многоходовый `chat`, [tool calling](tools.md).
- **Async-first** — [`AsyncBroker`](async.md); `Broker` — блокирующая обёртка того же движка.
- **Самообучающийся пул** — [оценивайте ответы](usage.md#quality), слабые модели
  уходят в конец очереди.
- **Ключи где угодно** — окружение, `.env`, БД, [AWS, Vault](secrets.md) или свой бэкенд.
- **Масштабирование без изменения кода** — [общая БД](server.md) на несколько
  инстансов, свой ключ на пользователя.
- **[Отключение моделей](disable.md)** вручную и снимок состояния пула.

Полный справочник API — [Reference](reference.md).
