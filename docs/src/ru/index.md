# llmbroker

Объедините множество бесплатных, ограниченных лимитами LLM, так что их суммарная доступность
складывается в надежное качественное решение без необходимости оплаты премиум-модели.

Никаких тяжёлых зависимостей наподобие LangChain.

## Быстрый старт

Возьмите готовый пул или напишите свой `llms.toml` (см. [Использование](usage.md)):

```bash
llmbroker preset freetier > llms.toml
```

Посмотрите, какие API-ключи нужны, получите их у провайдеров и установите:

```bash
llmbroker env llms.toml > .env
```

Каждый провайдер выдаёт свой ключ (регистрация на бесплатном тарифе занимает около
минуты). `.env`-файл — самый простой вариант, но секреты могут браться и из переменных
окружения, AWS, Vault или любого подключённого бэкенда. Затем вызовите брокер:

```python
import llmbroker

llms = llmbroker.Broker("llms.toml")
print(llms.ask("Привет, как дела?").text)
```

Если один LLM заблокирован по rate limit, брокер охладит его и переключится на следующий.
Вызывающий код не видит ошибку лимита, пока хотя бы один LLM доступен.

## Как это работает

- Каждому LLM в пуле соответствует один слот очереди: не более одного активного
  запроса к LLM одновременно.
- Когда LLM заблокирован по rate limit или недоступен, брокер ставит его на паузу
  (`cooldown`) и повторно добавляет в очередь после задержки (`Retry-After` из
  заголовка провайдера или 60 с по умолчанию).
- `ask(prompt)` — обёртка над `chat([{"role": "user", "content": prompt}])`.
- Если все LLM на паузе и истёк `wait` — `NoLLMAvailableError`.
- Если LLM попробован и вернул ошибку — `AllLLMsFailedError`.

`AsyncBroker` — основной движок (FastAPI, агенты, асинхронные воркеры); `Broker` —
блокирующая обёртка, показанная выше. См. [Использование](usage.md): оба режима,
инструменты и мультипользовательский режим.
